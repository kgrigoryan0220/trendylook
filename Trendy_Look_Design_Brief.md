# Trendy Look — ТЗ для дизайн-прототипа (Claude Design)

**Задача:** собрать полностью кликабельный мобильный прототип (iOS-стиль, portrait, ~390×844) приложения Trendy Look — AI-стилист, который оценивает трендовость образа по фото.

Ниже — исчерпывающая спецификация: стиль, экраны, состояния, компоненты и карта переходов. Экраны должны быть реально кликабельными: кнопки и карточки ведут на соответствующие экраны/состояния, а не просто нарисованы.

---

## 0. Важные решения (исправлены нестыковки исходного ТЗ)

- В MVP — **один** шаблон share-карточки (не три).
- **Без** отдельного экрана "occasion selector" (casual/office/party) — это v2.
- На пейволле бейдж half-year — просто **«Best value»**, без конкретного «−40%».
- Добавлено состояние **«Grace period»** для истёкшей-но-ещё-активной подписки (24ч).
- Добавлена **нижняя таб-бар навигация** (Home / История / Профиль) — в исходном ТЗ не была явно описана, но нужна для целостного прототипа.
- Sticker export как отдельная фича — не проектируем (v2). Кнопка «Поделиться» ведёт сразу к нативному шеринг-листу с одной карточкой.

---

## 1. Тон и позиционирование

- Продукт: мгновенная, «шерибельная» оценка образа + рекомендации от AI.
- Аудитория: Gen Z / молодые миллениалы (16–30), fashion-curious, UGC-креаторы.
- Ощущение от интерфейса: дерзко, ярко, по-приятельски, никакого занудства. Как открыть Duolingo/BeReal, а не банковское приложение.
- Язык интерфейса в макете: русский (основной), с пометками, что строки должны легко переноситься на EN.

## 2. Дизайн-система

### Цвет
Тёмная тема как основная (лучше продаёт неон и share-контент), плюс общий принцип для светлой — но для прототипа делаем **тёмную тему** как основной вариант.

- Фон: почти чёрный `#0B0B10`
- Поверхность карточек: `#17171F`
- Акцент 1 (electric pink): `#FF3D8A`
- Акцент 2 (lime): `#C6FF3D`
- Акцент 3 (violet): `#7B5CFF`
- Градиент score-ring: pink → violet (`#FF3D8A` → `#7B5CFF`)
- Успех / высокий score (80%+): lime `#C6FF3D`
- Текст основной: `#FFFFFF`, вторичный: `#9A9AA8`
- Ошибка/предупреждение: `#FF5C5C`

### Типографика
- Display/заголовки: жирный, крупный geometric sans (аналог Clash Display) — цифры score должны быть огромными, до 96–120px на результате.
- Body: чистый sans (аналог Inter/Satoshi), 14–16px.

### Форма и иконки
- Радиусы: 20–24px на карточках, pill-кнопки (radius 999).
- Иконки: outline, 2px stroke, лаконичные (аналог Lucide).
- Кнопки: primary — заливка градиентом pink→violet; secondary — обводка/стекло (glassmorphism на тёмном фоне).

### Анимационные принципы (отразить статично + пометкой на кликабельном прототипе, где это анимация)
- Score-ring "накручивается" от 0 до N% при появлении результата.
- При score ≥80% — конфетти.
- Skeleton/pulse на loading-экране.
- Микро-haptic-ощущение кнопок (легкий scale при tap, если можно показать в интерактиве).

## 3. Глобальная навигация

Нижний таб-бар (3 вкладки), виден на Home / История / Профиль:
- 🏠 Главная
- 🕘 История
- 👤 Профиль

Флоу «Проверка лука» (камера → загрузка → анализ → результат → шеринг) — full-screen модальный поток поверх таб-бара, без таб-бара внутри самого флоу (это фокус-режим).

Paywall — full-screen модалка, вызывается контекстно (из Home при исчерпании лимита, из Профиля вручную).

---

## 4. Полный список экранов

Для каждого экрана — назначение, состояния и **явные клик-переходы** (что куда ведёт).

### 4.1 Splash
- Лого + фон с намёком на градиент. Авто-переход (в прототипе — клик в любое место) → Onboarding (если первый запуск) или Home (если уже авторизован — сделать как отдельный "быстрый вход" вариант необязателен, для прототипа всегда идём в Onboarding).

### 4.2 Onboarding (3 слайда + progress dots)
1. «Сфотографируй свой лук» — иллюстрация камеры.
2. «Узнай % трендовости» — анимированный score-ring (статично для прототипа, показать крупное число, например 82%).
3. «Получи советы от AI» — карточки рекомендаций-превью.
- Свайп/кнопка "Далее" между слайдами, на 3-м — кнопка **«Начать»**.
- Есть **«Пропустить»** в правом верхнем углу на всех слайдах.
- Клики: Далее → следующий слайд; Начать / Пропустить → Auth.

### 4.3 Auth
- Лого + слоган.
- Кнопка **«Войти через Apple»** (чёрная, iOS-style).
- Кнопка **«Войти через Google»** (белая/аутлайн).
- Мелкий текст внизу: ссылки на Terms / Privacy (некликабельные плейсхолдеры допустимы).
- Клик по любой кнопке входа → Home (Empty state, см. 4.4).

### 4.4 Home — 3 состояния
**A. Empty state (новый юзер, 0 проверок)**
- Hero-блок: «Проверь свой лук» + крупная кнопка **«Сфотографировать»** и вторичная **«Из галереи»**.
- Counter: «Осталось бесплатных проверок: 2»
- Блок «Последние проверки» скрыт или показывает пустую подсказку "Здесь появится твоя история".

**B. С историей (есть проверки, лимит не исчерпан)**
- Те же hero-кнопки.
- Counter: «Осталось бесплатных проверок: 1»
- Горизонтальный скролл «Последние проверки» — карточки с мини-фото + score-бейдж. Клик по карточке → Экран результата (read-only, см 4.8).

**C. Pro/безлимит (badge)**
- Вместо counter — бейдж **«PRO»** / «Безлимит».
- Остальное аналогично B.

Клики: «Сфотографировать» → Camera capture (4.5). «Из галереи» → Gallery confirm (4.6). Таб-бар работает отовсюду.
Если лимит исчерпан (0 проверок) и юзер жмёт «Сфотографировать»/«Из галереи» → сразу Paywall (4.9), а не камера.

### 4.5 Camera capture
- Полноэкранный видоискатель (мокап, статичное фото-плейсхолдер).
- Кнопка спуска затвора (крупный круг снизу по центру).
- Переключатель фронт/тыл камера (иконка сверху).
- Крестик закрытия — сверху слева → назад на Home.
- После "съёмки" (клик по затвору) → Crop/Confirm экран.

### 4.6 Crop / Confirm фото
- Превью снятого/выбранного фото с рамкой кропа.
- Кнопки: **«Пересъёмка»** (назад на Camera) и **«Подтвердить»**.
- Подтвердить → Loading/Analysis (4.7).

### 4.7 Loading / Анализ
- Блюр-превью фото на фоне.
- Анимация сканирующей линии (статично показать линию по центру).
- Ротация фраз (показать одну фразу как пример): «Сверяем с трендами 2026…»
- Прогресс-бар снизу.
- Авто-переход (клик в любое место экрана в прототипе) → Result (4.8).

### 4.8 Result — core viral screen (2 варианта состояния по score)
Структура:
- Фото пользователя как фон/шапка.
- Крупный score-ring по центру (пример: 78%, лейбл «TRENDY»).
- Шкала лейблов для справки дизайнеру (не показывать все на экране, использовать нужный по состоянию):
  - 0–39 → «Needs Work» (красный акцент)
  - 40–59 → «Getting There» (жёлто-акцентный)
  - 60–79 → «Trendy» (pink/violet)
  - 80–100 → «Icon Status» (lime, + конфетти)
- Блок категорий с иконками: Цветовая палитра, Силуэт и посадка, Аксессуары, Обувь — каждая с мини-баром/score.
- Блок «💡 Рекомендации» — 3–5 пунктов с приоритетом (нумерованный список, первый пункт визуально акцентирован).
- Две кнопки внизу: **«Поделиться»** и **«Ещё раз»**.

**Состояние 1 — обычный результат (score 60–79%)**
**Состояние 2 — топовый результат (score 80%+)** — конфетти-оверлей, более праздничный акцент.

Клики: «Поделиться» → Share preview (4.10). «Ещё раз» → если лимит не исчерпан → Camera capture (4.5); если исчерпан → Paywall (4.9). Крестик/назад сверху → Home.

### 4.9 Paywall
- Заголовок: «Открой безлимит» / «Проверяй сколько хочешь».
- Карточки тарифов рядом:
  - **Weekly** — $4.99 / 399 ₽ за 7 дней.
  - **Half-year** — $29.99 / 1 990 ₽ за 6 месяцев, бейдж **«Best value»** (без конкретной цифры скидки).
- Список преимуществ с иконками: безлимит проверок, полная история, расширенные рекомендации, share без водяного знака.
- Social proof строка: «12 000+ проверок сегодня».
- Кнопка **«Продолжить»** (главная, ведёт по факту к «покупке» — в прототипе просто первый клик).
- Отдельная кнопка/ссылка **«Восстановить покупки»**.
- Внизу мелкие ссылки Terms / Privacy.
- Крестик закрытия сверху → назад туда, откуда пришли (Home или Result).

Дополнительное состояние (после «покупки» в прототипе): **Success toast/экран** «Готово! Теперь у тебя безлимит 🎉» → авто-переход на Home (состояние Pro, 4.4C).

**Grace period состояние** (отдельный маленький баннер на Home/Профиле): жёлтая плашка «Подписка истекает — обнови способ оплаты» с кнопкой «Обновить», актуально когда `sub_status` в статусе grace 24ч.

### 4.10 Share preview
- Превью карточки 9:16 (Stories формат): фото, score, 1 топ-рекомендация, лого/бренд, QR/deep-link.
- Кнопка **«Поделиться»** (открывает нативный share sheet — можно показать как bottom sheet с иконками соцсетей: Instagram, TikTok, WhatsApp, Скопировать ссылку).
- Кнопка «Назад» → Result.

### 4.11 История — 2 состояния
**A. Пусто** (нет проверок) — иллюстрация + текст «Здесь появится твоя история проверок» + CTA «Сделать первую проверку» → Camera capture.

**B. Список/грид** — карточки: миниатюра фото, score-бейдж, дата. Свайп влево на карточке → появляется кнопка «Удалить» → модалка подтверждения (4.13).
Клик по карточке → Детальный просмотр (4.12).

### 4.12 Детальный просмотр (история, read-only)
- То же визуальное решение, что Result (4.8), но без кнопок «Поделиться»/«Ещё раз» — вместо них одна кнопка **«Поделиться»** (можно шерить старый результат) и кнопка «Назад».

### 4.13 Модалка подтверждения удаления
- Bottom sheet: «Удалить эту проверку?» + кнопки «Отмена» / «Удалить» (красная).

### 4.14 Профиль
- Аватар + имя + email (из Apple/Google).
- Статус подписки: «Free» / «Pro до {дата}» / «Grace period».
- Остаток бесплатных проверок (если Free).
- Список настроек: Уведомления (заглушка), Язык (RU/EN), Поддержка, Privacy Policy, Terms of Service.
- Кнопка **«Выйти»** внизу (красный текст) → модалка подтверждения → Auth.
- Если Free — кнопка/баннер **«Перейти на Pro»** → Paywall.

### 4.15 Ошибки / edge cases (спроектировать как отдельные состояния)
- **Нет доступа к камере** — модалка с иконкой камеры, текст «Разреши доступ к камере в настройках», кнопка «Открыть настройки» (заглушка) и «Отмена».
- **Ошибка анализа** (fallback CHECK-08) — на месте Result: иконка ошибки, текст «Не получилось проанализировать фото. Попробуй ещё раз — проверка не списана», кнопка «Повторить».
- **Нет интернета** — компактный баннер сверху экрана «Нет соединения».

## 5. Переиспользуемые компоненты (вынести отдельным блоком в файле, если Claude Design это поддерживает)

- **Score Ring** — круговой прогресс с числом по центру, 4 цветовых состояния по шкале лейблов.
- **Recommendation Card** — иконка приоритета, заголовок, короткое описание.
- **Category Bar** — иконка + название + мини progress bar.
- **Plan Card** (paywall) — цена, период, бейдж (опционально), список фич.
- **History Item** — thumbnail + score badge + дата, с свайп-состоянием.
- **Bottom Tab Bar** — 3 иконки, активное состояние выделено акцентным цветом/подложкой.
- **Primary Button** (pill, градиент) / **Secondary Button** (pill, обводка).
- **Bottom Sheet** (для share sheet и confirm-модалок).

## 6. Карта кликов (сквозной сценарий для проверки прототипа)

```
Splash → Onboarding(1→2→3) → Auth →
Home(Empty) → [Сфотографировать] → Camera → Crop/Confirm → Loading → Result(обычный)
  → [Поделиться] → Share preview → [Поделиться] → (share sheet)
  → [Ещё раз] → Camera → ... → Result(2-я проверка)
  → [Ещё раз] (лимит исчерпан) → Paywall → [Продолжить] → Success → Home(Pro)

Home → таб «История» → История(список) → карточка → Детальный просмотр → назад
История → свайп карточки → [Удалить] → модалка подтверждения → назад в список

Home → таб «Профиль» → Профиль → [Выйти] → модалка → Auth
Профиль(Free) → [Перейти на Pro] → Paywall
```

Все переходы выше должны быть реально кликабельны в прототипе (не просто нарисованные кнопки).

---

## 7. Из MVP исключено — НЕ проектировать

- Occasion selector (casual/office/party)
- Несколько шаблонов share-карточки (только 1)
- Referral / приглашение друзей
- Before/After сравнение
- Leaderboard
- Push-уведомления как реальный флоу (можно оставить пункт в настройках как заглушку)
- Sticker export отдельно от share-карточки
- In-app чат поддержки (в Профиле — просто ссылка/заглушка "Поддержка")
